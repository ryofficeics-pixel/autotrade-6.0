# Dashboard decisions

Reading this as: a paper-trading safety console for an owner deciding whether new exposure is authorized, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

- The existing dark, low-motion console remains because operators monitor it for extended periods and high contrast reduces fatigue.
- Pair Safety is a plain table because the decision is pair-specific authorization, not portfolio performance decoration.
- Green and red remain restricted to allowed and denied states so status does not depend on color alone.
- The dashboard uses Open Sans already included in the repository for legibility at dense operational sizes.

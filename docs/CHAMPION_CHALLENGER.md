# Champion / Challenger

The baseline is labeled a paper hypothesis, not a validated Champion. Daily evaluation records `REQUIRE_MORE_DATA` until the configured closed-trade minimum exists, then only `KEEP`; it cannot promote code or parameters automatically.

A future candidate must pass train/validate/out-of-sample/walk-forward, lookahead and recursive checks, fee/slippage stress, adequate trade count, and dry/shadow evidence. Deployment must use versioned artifacts and retain rollback. Raw backtest profit alone cannot promote anything.
